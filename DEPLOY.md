# 🚀 VERCEL DEPLOYMENT GUIDE

## Quick Deploy to Vercel

### Step 1: Push to GitHub
```bash
cd /path/to/asokamanpower
git init
git add .
git commit -m "Initial commit - Go Hire Consultancy"
git branch -M main
git remote add origin https://github.com/yourusername/gohire-consultancy.git
git push -u origin main
```

### Step 2: Deploy on Vercel

1. **Sign up / Login**: [vercel.com](https://vercel.com)
2. **New Project** → Import Git Repository
3. **Select** your GitHub repo
4. **Framework Preset**: Other (vanilla HTML/CSS/JS)
5. **Root Directory**: `./` (default)

## Custom Domain Setup

### Add Domain in Vercel:
1. Go to: Project → Settings → Domains
2. Add your domain: `gohireconsultancy.com`
3. Vercel provides DNS records

### Update DNS (at your domain registrar):

**For root domain:**
```
Type: A
Name: @
Value: 76.76.21.21
```

**For www subdomain:**
```
Type: CNAME
Name: www
Value: cname.vercel-dns.com
```

**SSL Certificate**: Auto-generated by Vercel (Let's Encrypt)

## Continuous Deployment

Every `git push` to `main` branch auto-deploys to production.

To deploy from a different branch:
1. Vercel Dashboard → Settings → Git
2. Set Production Branch to your preferred branch
